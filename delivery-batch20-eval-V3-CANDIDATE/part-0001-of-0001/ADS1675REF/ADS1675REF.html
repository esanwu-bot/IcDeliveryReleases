ADS1675REF 24-Bit ADC, 4MSPS, TQFP-64

The ADS1675 is a high-speed, high-precision 24-bit analog-to-digital converter with 103dB dynamic range at 4MSPS and 111dB at 125kSPS.

P

ADS1675REF Overview

ADS1675REF features a dual-path programmable digital filter with selectable Low-Latency or Wide-Bandwidth paths, operates from +5V analog and +3V digital supplies, and supports both CMOS and LVDS serial interfaces. Designed for automated test equipment, medical imaging, and scientific instrumentation.

Key capabilities include 4MSPS, 24-bit analog-to-digital converter with 103dB dynamic range at 4MSPS and 111dB at 125kSPS; dual-path programmable digital filter with selectable Low-Latency or Wide-Bandwidth paths; low-Latency filter settles in as fast as 2.65ms.

It is used in Automated Test Equipment, Medical Imaging, Scientific Instrumentation, Test and Measurement.

ADS1675REF is supplied in the TQFP-64 package with 64 pins, an operating range of -40°C to +85°C, and 6 documented orderable options.

The values on this page come from the Texas Instruments datasheet (source PDF).

Technical Insight

What should be checked when designing with ADS1675REF?

  • Respect the Absolute Maximum Rails: Absolute maximum ratings limit AVDD to AGND to -0.3 to +5.5 V; DVDD to DGND to -0.3 to +3.6 V. Design the supply sequence and transients inside these limits before selecting surrounding components.
  • Budget the Thermal Headroom: Operating temperature is -40°C to +85°C, storage -60°C to +150°C. Derating, self-heating and airflow must be verified at the worst-case ambient of the enclosure.
  • Lock the Package and Pinout Early: The TQFP-64 (64 pins), 10mm x 10mm defines the footprint, thermal path and pin assignment; confirm it against the current revision before layout.

Pinout

The TQFP-64 pin assignment groups 30 unique pin functions across 64 terminals.

  • 1, 7, 11, 12, 58 - AVDD: Analog supply
  • 2, 3, 6, 9, 10, 54, 56, 57 - AGND: Analog ground
  • 4 - AINN: Negative analog input
  • 5 - AINP: Positive analog input
  • 8 - RBIAS: Analog bias setting resistor
  • 13 - VCM: Terminal for external bypass capacitor connection to internal common-mode voltage
  • 14, 15, 16, 17, 18, 19, 20, 25, 26, 31, 50, 51 - DGND: Digital ground
  • 21 - RSV2: Reserved, short pin to digital ground
  • 22 - RSV1: Reserved, short pin to digital supply
  • 23, 24, 27, 47, 48, 49, 52, 53 - DVDD: Digital supply
  • 28 - PDWN: Power-down control, active low
  • 29 - SCLK_SEL: Shift-clock source select. If SCLK_SEL = '0', then SCLK is internally generated. If SCLK_SEL = '1', then SCLK must be externally generated.
  • 30 - LVDS: Serial interface select. If LVDS = '0', then interface is LVDS-compatible. If LVDS = '1', then interface is CMOS-compatible.
  • 32 - LL_CONFIG: Configure Low-Latency digital filter. If LL_CONFIG = '0', then single-cycle settling is selected. If LL_CONFIG = '1', then fast-response is selected.
  • 33 - FPATH: Digital filter path selection. If FPATH = '0', then path is Wide-Bandwidth. If FPATH = '1', then path is Low-Latency.
  • 34 - DRATE[2]: Data rate selection
  • 35 - DRATE[1]: Data rate selection
  • 36 - DRATE[0]: Data rate selection
  • 37 - START: Start convert, reset, and synchronization control input
  • 38 - CS: Chip select; active low
  • 39 - OTRD: Digital filter out-of-range indicator
  • 40 - OTRA: Analog input out-of-range indicator
  • 41, 42 - SCLK: Negative shift clock output. If SCLK_SEL = '0', then SCLK is the complementary shift clock output. If SCLK_SEL = '1', then SCLK always output is 3-state.
  • 43, 44 - DOUT: Negative LVDS serial data output
  • 45, 46 - DRDY: Negative data ready output
  • 55 - CLK: Master clock input
  • 59 - CAP1: Terminal for 1µF external bypass capacitor
  • 60, 61 - VREFN: Negative reference voltage. Short to analog ground
  • 62 - CAP2: Terminal for 1µF external bypass capacitor
  • 63, 64 - VREFP: Positive reference voltage

Which electrical limits matter most for ADS1675REF?

The headline specifications are Full-scale input voltage = ±VREF, Common-mode input voltage = 2.5 V, Dynamic range = 100 dB, and Dynamic range = 103 dB. Always read them together with the stated test conditions.

What must be checked before laying out ADS1675REF?
