ADS1201U-1/1K の概要

ADS1201は、単一+5V電源で動作する、130dBのダイナミックレンジを備えた精密なデルタシグマ（ΔΣ）変調器です。フルディフェレンシャル入力、2-wireインターフェース、およびオンチップ較正スイッチを特徴とします。適切なデジタルフィルタと変調率により、コード欠落なしの24ビットのA/D変換を実現できます。高解像度計測アプリケーション向けに設計されています。

主な特長：130dB dynamic range、Fully differential input、Two-wire interface。

用途：Industrial process control、Instrumentation、Smart transmitters、Portable instruments。

ADS1201U-1/1K is supplied in the SOIC-16 package with 16 pins, an operating range of -40°C to +85°C, and 4 documented orderable options.

P

ピン配置

SOIC-16 のピン割り当ては、16 端子に 16 種類のピン機能を割り当てたものです。

  • 1 - AVDD: Analog Supply, +5V nominal
  • 2 - REFOUT: Internal Reference Voltage Output: +2.5V nominal
  • 3 - REFIN: Reference Voltage Input
  • 4 - NIC: Not Internally Connected
  • 5 - AINP: Noninverting Input
  • 6 - AINN: Inverting Input
  • 7 - AGND: Analog Ground
  • 8 - VBIAS: Bias Voltage Output, nominally +3.3V (with +2.5V reference)
  • 9 - BIASEN: Bias Voltage Enable Input (HIGH = enabled, LOW = disabled)
  • 10 - GAIN/OFFSET: Gain/Offset Calibration Select Input
  • 11 - CAL: Calibration Control Input (HIGH = normal operation, LOW = gain or offset calibration)
  • 12 - DGND: Digital Ground
  • 13 - DVDD: Digital Supply, +5V nominal
  • 14 - MCLK: Modulator Clock Input. CMOS compatible.
  • 15 - MOUT: Modulator Output
  • 16 - REFEN: REF OUT Voltage Enable Input (HIGH = enabled, LOW = disabled)

Which electrical limits matter most for ADS1201U-1/1K?

The headline specifications are Absolute Input Voltage Range = 0 to +5 V; Differential Input Voltage Range = –5 to +5 V; Input Impedance = 250(4) TYP kΩ; Input Capacitance = 8 TYP pF. Always read them together with the stated test conditions.

Use the current SOIC-16 drawing and pin assignment (16 pins), keep the operating range (-40°C to +85°C) inside the enclosure budget, and verify the supply rails against the absolute maximum ratings.
