ADS1675 4MSPS 24-Bit ADC with Dual-Path Filter, TI

The ADS1675 is a high-speed, high-precision 24-bit analog-to-digital converter with 103dB dynamic range at 4MSPS and 111dB at 125kSPS.

P

ADS1675REF Overview

ADS1675REF features a dual-path programmable digital filter with selectable Low-Latency or Wide-Bandwidth paths, operates from 5V analog and 3V digital supplies, and supports both CMOS and LVDS serial interfaces. Designed for automated test equipment, medical imaging, and scientific instrumentation.

Key capabilities include AC Performance: 103dB of Dynamic Range at 4MSPS, 111dB of Dynamic Range at 125kSPS, –107dB THD; DC Accuracy: 3ppm INL, 4mV/°C Offset Drift, 4ppm/°C Gain Drift; programmable Digital Filter with User-Selectable Path: Low-Latency (completely settles in 2.65ms), Wide-Bandwidth (1.7MHz BW with flat passband).

It is used in Automated Test Equipment, Medical Imaging, Scientific Instrumentation, Test and Measurement.

ADS1675REF is supplied in 6 documented orderable options.

The values on this page come from the Texas Instruments document (source PDF).

Pinout

The package pin assignment groups 30 unique pin functions across 64 terminals.

  • 1, 7, 11, 12, 47, 53, 58 - AVDD: Analog supply
  • 2, 3, 6, 9, 10, 54, 56, 57 - AGND: Analog ground
  • 4 - AINN: Analog input, Negative analog input
  • 5 - AINP: Analog input, Positive analog input
  • 8 - RBIAS: Analog, Analog bias setting resistor
  • 13 - VCM: Analog, Terminal for external bypass capacitor connection to internal common-mode voltage
  • 14, 15, 16, 17, 18, 19, 20, 25, 26, 31, 50, 51 - DGND: Digital, Digital ground
  • 21 - RSV2: Reserved, Short pin to digital ground
  • 22 - RSV1: Reserved, Short pin to digital supply
  • 23, 24, 27, 48, 49, 52 - DVDD: Digital, Digital supply
  • 28 - PDWN: Digital input, Power-down control, active low
  • 29 - SCLK_SEL: Digital input, Shift-clock source select. If SCLK_SEL = '0', then SCLK is internally generated. If SCLK_SEL = '1', then SCLK must be externally generated.
  • 30 - LVDS: Digital input, Serial interface select. If LVDS = '0', then interface is LVDS-compatible. If LVDS = '1', then interface is CMOS-compatible.
  • 32 - LL_CONFIG: Digital input, Configure Low-Latency digital filter. If LL_CONFIG = '0', then single-cycle settling is selected. If LL_CONFIG = '1', then fast-response is selected.
  • 33 - FPATH: Digital input, Digital filter path selection. If FPATH = '0', then path is Wide-Bandwidth. If FPATH = '1', then path is Low-Latency.
  • 34 - DRATE[2]: Digital input, Data rate selection
  • 35 - DRATE[1]: Digital input, Data rate selection
  • 36 - DRATE[0]: Digital input, Data rate selection
  • 37 - START: Digital input, Start convert, reset, and synchronization control input
  • 38 - CS: Digital input, Chip select; active low
  • 39 - OTRD: Digital output, Digital filter out-of-range indicator
  • 40 - OTRA: Digital input, Analog input out-of-range indicator
  • 41, 42 - SCLK: Digital output, Negative shift clock output. If SCLK_SEL = '0', then SCLK is the complementary shift clock output. If SCLK_SEL = '1', then SCLK always output is 3-state.
  • 43, 44 - DOUT: Digital output, Negative LVDS serial data output
  • 45, 46 - DRDY: Digital output, Negative data ready output
  • 55 - CLK: Digital input, Master clock input
  • 59 - CAP1: Analog, Terminal for 1mF external bypass capacitor
  • 60, 61 - VREFN: Analog, Negative reference voltage. Short to analog ground
  • 62 - CAP2: Analog, Terminal for 1mF external bypass capacitor
  • 63, 64 - VREFP: Analog, Positive reference voltage
