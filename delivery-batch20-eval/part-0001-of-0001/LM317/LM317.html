LM317 Adjustable Voltage Regulator 1.5A, 1.25V-37V, TI

The LM317 is a three-pin adjustable positive voltage regulator capable of supplying up to 1.5A over an output voltage range of 1.25V to 37V.

P

LM317 Overview

LM317 features low line and load regulation, internal current limiting, thermal overload protection, and safe-area compensation. Suitable for applications requiring precision voltage regulation in power supplies, printers, servo drives, and industrial systems.

Key capabilities include output voltage range: 1.25V to 37V; output current: 1.5A; line regulation: 0.01%/V (typ).

It is used in Multifunction printers, AC drive power stage modules, Electricity meters, Servo drive control modules.

LM317 is supplied in the SOT-223 (DCY), TO-263 (KTT), TO-220 (KCS, KCT) package with 3 pins, an operating range of 0°C to 125°C, and 15 documented orderable options.

The values on this page come from the Texas Instruments datasheet (source PDF).

Technical Insight

What should be checked when designing with LM317?

  • Respect the Absolute Maximum Rails: Absolute maximum ratings limit Input-output voltage differential to -0.3 to 40 V. Design the supply sequence and transients inside these limits before selecting surrounding components.
  • Budget the Thermal Headroom: Operating temperature is 0°C to 125°C, storage -65°C to 150°C. Derating, self-heating and airflow must be verified at the worst-case ambient of the enclosure.
  • Lock the Package and Pinout Early: The SOT-223 (DCY), TO-263 (KTT), TO-220 (KCS, KCT) (3 pins), 6.5mm x 7mm (DCY), 10.16mm x 15.24mm (KTT), 10.16mm x 4.55mm (KCS/KCT) defines the footprint, thermal path and pin assignment; confirm it against the current revision before layout.

Package

LM317 uses the SOT-223 (DCY), TO-263 (KTT), TO-220 (KCS, KCT) package with 3 pins.

The device is specified with body dimensions of 6.5mm x 7mm (DCY), 10.16mm x 15.24mm (KTT), 10.16mm x 4.55mm (KCS/KCT), an operating temperature range of 0°C to 125°C, and a storage range of -65°C to 150°C. Confirm the mechanical drawing in the current datasheet revision before release to production.

P

Pinout

The SOT-223 (DCY), TO-263 (KTT), TO-220 (KCS, KCT) pin assignment groups 3 unique pin functions across 3 terminals.

  • 1 - ADJUST: Output voltage adjustment pin. Connect to a resistor divider to set VOUT.
  • 2 - OUTPUT: Output voltage pin for the regulator.
  • 3 - INPUT: Input voltage pin for the regulator.

Which electrical limits matter most for LM317?

The headline specifications are Reference voltage = 1.25 V, Line regulation = 0.01 to 0.04 %/V, Load regulation = 0.1 to 0.5 %VO, and Thermal regulation = 0.04 to 0.07 %/W. Always read them together with the stated test conditions.

What must be checked before laying out LM317?

Use the current SOT-223 (DCY), TO-263 (KTT), TO-220 (KCS, KCT) drawing and pin assignment (3 pins), keep the operating range (0°C to 125°C) inside the enclosure budget, and verify the supply rails against the absolute maximum ratings.
