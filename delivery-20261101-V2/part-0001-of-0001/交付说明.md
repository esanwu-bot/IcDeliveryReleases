# 交付说明（1102）

## 这是什么

五型号（ADC12DJ5200SE / ADS1201U-1/1K / ADS8568EVM-PDK / BOOST-DRV8711 / BOOSTXL-C2KLED）
的详情页物料与解析 JSON 交付包，**复核候选版**，不是已批准上线的正式版本。

- `release_status` 全部 `not_approved`
- `release_state` 最高到 `IDENTITY_APPROVED`；`CONTENT_APPROVED` / `RELEASE_APPROVED` 需人工签核
- `i18n_validation = not_checked`

**打包校验通过不等于工程验收通过，不应直接上线或用于电路设计。**

## 怎么用这个包核对

1. 打开 `manifest.csv`，看每件的 `gate` / `release_state` / `facts_verdict`。
2. 打开 `facts_audit.csv`，这是**逐行**的 PDF 回打结果：
   `verified`（确定性复现）/ `value_on_label_page`（值与参数名同页）/
   `value_in_pdf`（只在别处出现，归属未证）/ `not_found`（原文找不到）。
3. 需要怀疑某一行时，直接打开该型号目录下的 `<型号>.pdf`，
   按 `facts_audit.csv` 里给的页码翻过去对照。**包内 PDF 就是解析用的那一份**，
   `pdf_sha256_packaged` 可与 `pdf_sha256_recorded` 独立比对。
4. `risk_queue.csv` 是待处理清单，每行带 `suggested_action`。

## 物料

每个型号目录内：

| 文件 | 说明 |
|---|---|
| `<型号>.json` | 解析结果（含 `metadata.core_sha256` 指纹） |
| `<型号>.html` | 详情页片段（不是整页，无 `<head>`） |
| `<型号>.symbols.html` | 三视图 / 板卡说明页 |
| `<型号>.pdf` | **原厂 PDF 原件**（1102 起必带） |
| `<型号>.alts.json` / `.alts.html` | 替代型号（仅站内目录命中的） |
| `<型号>.seo.json` | 标题 / meta / 多语标题 |
| `<型号>.ja/.ko/.de/.es.html` | 多语片段 |
