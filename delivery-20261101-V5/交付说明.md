# 交付说明（delivery-20261101-V5）

> 与 `delivery-20261101-V4` 的差异集中在**四件事**：
> ① 板卡参数拆成「整板 / 板载器件 / 未定」三桶，不再混在同一张表；
> ② 分类面包屑真正上页面（V4 只在 JSON 里）；
> ③ 韩语页 6 段英文模板句清零，`i18n_complete` 改为**实测覆盖率**；
> ④ `release_state` 收紧 —— `DATA_VALIDATED` 要求每行都锚到原厂表的具体行。
> 另有 `pin_desc_exempt` 管脚描述豁免声明，与《回复Reviewer.md》逐条答复。

## 这是什么

五型号（ADC12DJ5200SE / ADS1201U-1/1K / ADS8568EVM-PDK / BOOST-DRV8711 / BOOSTXL-C2KLED）
的详情页物料与解析 JSON 交付包，**复核候选版**，不是已批准上线的正式版本。

- `release_status` 全部 `not_approved`
- `release_state` 最高到 `DATA_VALIDATED`；`CONTENT_APPROVED` / `RELEASE_APPROVED` 需人工签核
- `i18n_complete` 为**实测值**（不再有 `not_checked` 占位）

**打包校验通过不等于工程验收通过，不应直接上线或用于电路设计。**

> **本包已包含全部原厂 PDF 原件**（五件，`<型号>/<型号>.pdf`），
> 复核方可对照包内 PDF 逐行复核任意一条参数，不需要外部下载、也不需要相信清单里的哈希。
> 1101 及以前的包不含原件，其 `pdf_sha256_recorded` 不能当证据用。

## 怎么用这个包核对

1. 打开 `manifest.csv`，看每件的 `gate` / `release_state` / `facts_verdict` / **`data_anchor`**。
   `data_anchor` 写「已锚定/总行数」—— 分子小于分母就说明有行只到「同页」，
   缺口在这里直接可见，不再藏在 `pass` 里。
2. 打开 `facts_audit.csv`，这是**逐行**的 PDF 回打结果，八级结论：
   `verified_row`（锚到具体表格行，带 `bbox` + `row_sha256`，可重放）/
   `verified_value` / `verified`（确定性复现）/
   `value_on_label_page`（值与参数名同页，行/列未证）/
   `value_in_pdf`（只在别处出现，归属未证）/
   `partial` / `unchecked` / `not_found`。
3. 需要怀疑某一行时，直接打开该型号目录下的 `<型号>.pdf`，
   按 `facts_audit.csv` 里给的页码与 `bbox` 翻过去对照。**包内 PDF 就是解析用的那一份**，
   `pdf_sha256_packaged` 可与 `pdf_sha256_recorded` 独立比对。
4. `risk_queue.csv` 是待处理清单，每行带 `suggested_action`
   （`human_review` 需人工看图确认 / `promote_to_deterministic` 可转确定性抽取）。
5. `txt/<型号>.i18n.json` 是多语覆盖率侧车：每语种的 `keys_used` / `key_fallbacks` /
   `narrative_fallbacks` / `ratio` 都在里面。**清单里的 `i18n_coverage` 就是从这里取的**，
   取所有语言里最低的那个。

## 板卡参数为什么分两张表

`BOOST-DRV8711` 的用户指南里同时有两类参数：

```
Voltage Range                    8.2 to 52 V    External power supply input   ← 整板
Continuous Current per H-Bridge  4.5 A          Max continuous                ← 板载 DRV8711
```

一个 `specs.scope` 值盖不住。V5 起按行打 `attribution`，页面上分成
`Board-level parameters` / `On-board device parameters` / `Attribution not determined`
三张表（单桶时不印标题，芯片页不受影响）。

`ADS8568EVM-PDK` 挂的 PDF 是 **ADS8568 的器件手册（SBAS543C）**，整板的电源/连接器
规格根本不在那份文件里 —— 所以它全部归 `onboard_device`，页面段首明写「整板规格源文档没有」。
**不假装有整板参数。**

## 管脚描述为什么保留英文

`pin_configuration` 的描述是管脚功能名（`VDD` / `AGND` / `SDO/SDI` / `No connect`）。
IEEE 器件手册与封装规格里这类文字按英文原样引用，译成目标语言反而与读者手上的
datasheet 对不上 —— 这是工程惯例，不是漏翻。

清单中 `pin_desc_exempt=true` 表示该型号适用此豁免，页面上有一行小字说明。
**豁免仅限 `pin_configuration`**；features / applications / description /
technical insight / FAQ 不豁免，仍按实测覆盖率考核。
