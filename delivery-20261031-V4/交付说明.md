# V4 交付说明（五型号，2026-10-31）

本包为 V3 复审后的修复版。**详细取证与逐条对照见同目录《V4_修复说明.md》**，
本文只讲包内有什么、边界在哪。

## 一、本版修了什么（三件）

1. **核心字段改为确定性抽取**：pins / 热阻 / ESD / VCMI / VID 不再由模型输出，
   改由 `qc/deterministic_extract.py` 从 PDF 文本层强制抽取。
   三次独立解析，这四个字段的 sha256 **完全一致**。
2. **页面侧补齐**：热阻与 ESD 此前**从未被渲染**（JSON 有、页面无）；
   未核验行加 `†` 角标与表头提示条（五语）；en 页 `<h1>` 改用 `seo.json` 标题。
3. **验收点变成可执行断言**：`ACCEPTANCE_SPECS` / `check_acceptance()`，
   不达标写进 `metadata.core_validation`，不是文档里的一句结论。

## 二、四验收点（JSON + 页面双侧）

| # | 验收点 | JSON | 页面 |
|---|---|---|---|
| 1 | VCMI 下限 | 3 条 `0 to 0.55 V`（CLK± / SYSREF± / TMSTP±） | `0 to 0.55` 出现 3 次 |
| 2 | VID | `0.4 to 2.0 VPP-DIFF` | 出现 1 次 |
| 3 | 热阻 + ESD | thermal 5 条、esd 2 条 | `23.9` / `0.8` / `8.4` / `0.23` / `±2000` / `±500` 全出现 |
| 4 | 球位 | 144 个球位号 | 页面唯一球位 token 144 |

## 三、五件的来源（必须看清）

| 型号 | 来源 | 说明 |
|---|---|---|
| ADC12DJ5200SE | 本次重解析 | 四验收点的对象 |
| ADS1201U-1/1K | 本次重解析 | 源文档无热阻表、无 ESD 数值 |
| ADS8568EVM-PDK | 本次重解析 | 评估板页，芯片参数不渲染成板级限值 |
| BOOST-DRV8711 | **沿用 V3** | 本次解析判为 User Guide，`is_datasheet()` 拦截 |
| BOOSTXL-C2KLED | **沿用 V3** | 同上 |

两件沿用不是静默替换：`_stage_report.json` 逐件记录 `source` 与 `reason`。
替代料侧车（`.alts.*`）同样沿用 V3 已复核版本 —— 它的输入是站内目录索引，
不是本次重解析的电气数据。

## 四、语言

三件重解析型号已补 ja/ko/de/es（`translate_i18n.py --scope full`，3/3 成功）。
两件沿用型号自带四语。语言完整性状态仍为 `not_checked`，
缺哪个变体由 manifest 的 `missing_html_languages` 列明。

## 五、可复现性怎么验

每个 `<型号>.json` 的 `metadata.core_sha256` 给出四个核心字段的 sha256：

```
pins     eb2145b82eb596ee…   (144)
thermal  4dd75f753101dc12…
esd      a594a1e8e76d13f9…
vcmi_vid e9baa1ab6c95c68c…   (4)
```

复跑同一份 PDF 后比这四个值即可。**不一致请拒收并回报**，不要用"本次看着对"验收。

## 六、边界（照旧）

**打包校验通过不等于工程验收通过。** 本包只装配指定验收根里已生成的物料，
不查数据库、不在打包时重渲染。`release_status` 仍为 `not_approved`。

仍不稳的部分：电气表里**模型抽的非核心行**两次运行仍会有差异
（行名措辞、个别值的写法），详见《V4_修复说明.md》§5.1。
